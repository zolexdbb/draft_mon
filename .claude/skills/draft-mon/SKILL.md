name: draft mon
description: reconstruit un site complet niveau agence à partir d'une description. Utilise ui-ux-pro-max pour la direction artistique et les composants 21st.dev via MCP.
---

À partir de la description fournie par l'utilisateur :
1. Invoque le skill ui-ux-pro-max pour choisir style, palette et
   typographies adaptés au secteur et à l'audience décrits.
2. Structure le site : hero, sections de valeur, preuve sociale,
   FAQ, CTA. Une page, responsive, mobile d'abord.
3. Pour chaque section, cherche un composant adapté via le MCP
   21st.dev et adapte-le à la palette choisie. Pas de composant
   inventé si un équivalent existe dans la bibliothèque.
4. Code le tout (HTML/CSS ou Next.js selon le projet ouvert),
   lance un serveur local, et donne l'URL de preview.
5. Termine par une auto-review design : contrastes, espacements,
   cohérence typographique. Corrige avant de rendre la main.
